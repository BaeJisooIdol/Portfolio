# Personal Portfolio Website

A responsive portfolio website built with React, TypeScript, and modern CSS frameworks.

## Features

- **Responsive Design**: Works on all device sizes
- **Dark/Light Mode**: Toggle between themes
- **Modern UI**: Clean and professional interface
- **Skills Section**: Visual representation of professional skills
- **Project Showcase**: Featuring key projects with GitHub links

## Technologies Used

- React
- TypeScript
- TailwindCSS
- Framer Motion
- Vite

## Projects Showcased

- **Online Course Website**: Built with JSP, Servlet, HTML/CSS, Bootstrap, JavaScript, SQL Server
- **Bakery and Coffee Website**: Built with JSP, Servlet, HTML/CSS, Bootstrap, JavaScript, SQL Server

## Setup and Installation

```bash
# Clone the repository
git clone https://github.com/BaeJisooIdol/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```
